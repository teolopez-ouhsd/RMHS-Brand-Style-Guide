# Spartans Brand Guide

Brand style guide for Rio Mesa High School (Oxnard Union High School District): official logos, colors, typography, accessibility, and usage rules.

## Publish on GitHub Pages

1. Create a new repository named `RMHS-Brand-Style-Guide`.
2. Upload everything in this folder: `index.html`, `logos/`, `sheets/`, `fonts/`, `videos/`, the .zip file, `.nojekyll`, and this README.
3. In the repo, go to **Settings > Pages**, set **Source** to "Deploy from a branch", choose `main` and `/ (root)`, and save.
4. After a minute the page will be live at `https://<your-username>.github.io/RMHS-Brand-Style-Guide/`.

## What's inside

- `logos/svg` and `logos/png`: 9 logo files, taken from the school's supplied brand kit files (one for one with the artboards in its Illustrator logo file), not redrawn. SVGs are trimmed to the artwork; PNGs are 2400px wide with transparent backgrounds.
- `rio-mesa-spartans-logos.zip`: every logo in both formats.
- `sheets/`: the original brand kit sheet as PNG and PDF.
- `fonts/`: Montserrat, Source Code Pro, and Open Sans (WOFF2, SIL Open Font License), so the page does not call an outside server.
- `videos/`: six silent how-to clips (logos, clear space, usage rules, color, typography, AI flyers), each as MP4 plus a WebM fallback and a poster image. They play when scrolled into view.

## Updating files

- Logos: replace files in `logos/svg` and `logos/png` with the same names, then rebuild `rio-mesa-spartans-logos.zip`.
- How-to videos: if the logos, colors, or rules change, the videos need to be re-made to match.
